# Données et images Fashion-MNIST

Les exemples de vêtements présents dans les figures et les fichiers
`error_samples.npz` proviennent de [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist).
Le jeu complet est téléchargé séparément et n'est pas inclus dans ce dépôt.

Référence : Han Xiao, Kashif Rasul et Roland Vollgraf (2017),
*Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning Algorithms*,
[arXiv:1708.07747](https://arxiv.org/abs/1708.07747).
